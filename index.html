Data and privacy

Your changes are stored locally in this browser on this device. Clearing browser data or changing devices may remove them. Export backups regularly. No financial account credentials are needed.

Install on iPhone

1. Host these files at an HTTPS website.

2. Open that URL in Safari.

3. Tap Share → Add to Home Screen → Add.

4. Launch Growth Radar from the Home Screen.

Data sources and limitations

Initial holdings and reference prices are based on the previously shared Robinhood screenshots and Stage 3 research notes. Version 2 supports optional quotes via a deployed Netlify function and in-app alerts while open. It has no cloud sync, background push alerts, or brokerage integration. The separate ChatGPT scheduled watchlist report does not automatically update this app.

Never embed private API keys in this public-facing app. Market data may be delayed or unavailable; check provider licensing and terms.
